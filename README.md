# AI Productivity Assistant

Build a single, responsive web application called AI Workplace Productivity Assistant that helps professionals automate workplace tasks using AI.

The application should include all of these features:

Smart Email Generator: It needs to be able to generate professional emails and support a variety of tones, for example, formal, casual, persuasive.

AI Task Planner: It should be able to generate daily schedules and prioritise managerial tasks.  

AI Research Assistant: It should be able to summarise topics/articles and provide insights and recommendations.

What it should have:

Modern dashboard UI

Sidebar navigation

Responsive design

Structured AI prompts

Editable AI outputs

Responsible AI disclaimer

Design style should be clean, modern, and professional, similar to a SaaS platform.
